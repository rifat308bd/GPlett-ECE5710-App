# ECE4710/5710: Battery Dynamics — Course Web App

A modern web app for browsing lecture notes (PDFs) and video recordings for the UCCS course **ECE4710/5710: Modeling, Simulation, and Identification of Battery Dynamics**.

## Features

- 📄 **PDF Viewer** — Embedded lecture notes viewer
- 🎬 **Video Player** — HTML5 video player with prev/next navigation
- ✅ **Progress Tracking** — Auto-marks videos as watched; persisted in localStorage
- 🔍 **Search** — Real-time filtering by topic title or number (`Ctrl+K`)
- 🔖 **Bookmarks** — Save and organize your favorite lectures
- 🌙 **Dark/Light Mode** — Toggle theme with saved preference
- 📱 **Responsive** — Works on desktop, tablet, and mobile

## Usage

Open `index.html` in a web browser — no build step or server required.

## Content

8 chapters, 84 lecture videos, and 8 PDF lecture note sets covering:

0. Course Introduction and Syllabus
1. Battery Boot Camp
2. Equivalent-Circuit Cell Models
3. Microscale Cell Models
4. Continuum (Porous-Electrode) Cell Models
5. State-Space Models and the DRA
6. Reduced-Order Models of Cell Dynamics
7. Thermal Modeling

All content is sourced from [UCCS ECE5710](http://mocha-java.uccs.edu/ECE5710/index.html).
